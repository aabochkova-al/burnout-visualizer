# Мой уровень выгорания

Веб-сервис для визуализации эмоционального выгорания через генерацию изображений (GigaChat).  
Пользователь задаёт параметры своего состояния (усталость, длительность стресса, количество кофе, стиль изображения), а система асинхронно генерирует уникальную картинку, сохраняет её в истории и позволяет добавлять в избранное.

---

## Стек технологий

- Java 21
- Spring Boot 3.5.14
- Spring Security (аутентификация, BCrypt)
- Spring Data JPA (Hibernate)
- PostgreSQL 14+
- Liquibase (миграции)
- Thymeleaf (шаблонизатор)
- GigaChat API (генерация изображений)
- Maven (сборка)

---

## Инструкция запуска

### 1. Установите Java 21

- Скачайте JDK 21: https://adoptium.net/
- Установите и проверьте в терминале:  
  ```bash
  java -version
  
Должно быть: openjdk version "21"

### 2. Установите PostgreSQL

Скачайте PostgreSQL:  https://www.postgresql.org/download/

Установите, запомните пароль суперпользователя postgres

### 3. Создайте базу данных

Откройте pgAdmin/DBeaver и выполните в командной строке:
```sql
CREATE DATABASE burnout_db;
CREATE USER burnout_user WITH PASSWORD 'burnout123';
GRANT ALL PRIVILEGES ON DATABASE burnout_db TO burnout_user;
```
### 4. Настройте конфигурацию приложения

Откройте файл src/main/resources/application.properties

Убедитесь, что строки подключения к БД верны:

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/burnout_db
spring.datasource.username=burnout_user
spring.datasource.password=burnout123
```
Создайте файл секретов 

src/main/resources/application-secrets.yml (не добавляйте в Git):

```yaml
gigachat:
  auth-key: "ваш_ключ_авторизации_GigaChat"
  scope: "GIGACHAT_API_PERS"
```
### 5. Запустите приложение

Вы можете использовать один из трёх способов:

- Способ 1 (через Maven):

```bash
mvn spring-boot:run
```
- Способ 2 (через JAR):

```bash
mvn clean package
java -jar target/visualizer-0.0.1-SNAPSHOT.jar
```
- Способ 3 (готовые скрипты)

На Mac/Linux:
```bash
./run.sh
```
 
На Windows:
```bash
run.bat
```

### 6. Откройте браузер

Перейдите по адресу: http://localhost:8080/register

### 7. Зарегистрируйтесь и войдите

Заполните форму регистрации (username, email, пароль)

Нажмите «Зарегистрироваться» -> перенаправление на /login

Войдите с созданными данными

## Тест-кейсы

### TC-01: Регистрация

Открыть http://localhost:8080/register

Ввести username, email, пароль

Нажать «Зарегистрироваться»

Ожидаемый результат: перенаправление на /login?registered, сообщение «Регистрация прошла успешно»

### TC-02: Вход в систему

На странице /login ввести username и пароль

Нажать «Войти»

Ожидаемый результат: переход на /dashboard, отображается форма генерации

### TC-03: Создание запроса (генерация изображения)

На дашборде заполнить поля:

Усталость: 7

Длительность: 30

Кофе: 4

Стиль: Абстрактный

Нажать «Сгенерировать образ»

Ожидаемый результат: в истории появляется запись со статусом PENDING, через 5–15 секунд статус меняется на SUCCESS и отображается сгенерированное изображение или ERROR при ошибке

### TC-04: Добавление в избранное

Дождаться успешной генерации изображения

Нажать на звёздочку ★ под картинкой в истории

Ожидаемый результат: изображение появляется в разделе «⭐ Избранное»

### TC-05: Повтор запроса

В истории запросов нажать кнопку «Повторить» в любой карточке

Проверить, что форма на дашборде заполнилась параметрами этого запроса

Изменить любой параметр (например, усталость с 7 на 5) и нажать «Сгенерировать»

Ожидаемый результат: создаётся новый запрос с изменёнными параметрами, статус PENDING -> SUCCESS (или ERROR)
